Módulos del Ciclo

Módulos del primer curso de Desarrollo de Aplicaciones Web.

Descripción de los módulos

Programación

Se aprenden los fundamentos de la programación: variables, estructuras de control, funciones y programación orientada a objetos.

Bases de Datos

Se estudia el diseño de bases de datos relacionales y el lenguaje SQL para consultar y modificar los datos.

Sistemas Informáticos

Se trabaja con el hardware, la instalación de sistemas operativos y la configuración básica de redes.

Lenguajes de Marcas

Se aprende a crear páginas web con HTML y CSS, y a trabajar con otros lenguajes de marcas como XML.

Entornos de Desarrollo

Se usan herramientas como editores de código, control de versiones y pruebas para desarrollar software.

Itinerario Personal para la Empleabilidad

Se trabajan los derechos laborales, la búsqueda de empleo y la orientación profesional.

Siglas de los módulos

  • PRO → Programación
  • BD → Bases de Datos
  • SI → Sistemas Informáticos
  • LM → Lenguajes de Marcas
  • ED → Entornos de Desarrollo
  • IPE → Itinerario Personal para la Empleabilidad
